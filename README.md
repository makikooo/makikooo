# 主な制作実績

## 【デザインスクール大津様】

- カテゴリ: 【LP】
- 期間: 【2024年】
- URL: 【 https://onof-design.com/ 】
- 役割: 【コーディング】
- 工夫した点:
  - 1ページ構成にして、ナビゲーションからページ内リンクで「特徴 → 身に付くスキル → 授業スタイル → 生徒の声」の順に読める流れにした
  - 無料体験の申し込み(LINE公式アカウント)へのボタンを、ヘッダー・ページ下部・フッターに置き、どの位置からでも申し込めるようにした
  - イラストや背景の装飾に SVG、写真に AVIF を使い、画質を保ちながらファイルサイズを抑えた
  - スマートフォン用の背景画像と短い説明文を用意し、画面幅に合わせて表示を切り替えた
  - 電話番号をタップで発信できるリンクにし、Google マップを埋め込んで教室の場所が分かるようにした
- 使用技術: HTML, CSS, GSAP

## 【イラストレーションスクール様】

- 期間:【 2024年 】 
- URL:【 https://illust-school.com/ 】
- 役割:【 デザイン、HTML / CSS コーディング 】
- 工夫した点:
  - 校舎が複数あるため、校舎ごとの「無料体験」ボタンをヘッダーとメインビジュアルの近くに並べ、通いたい校舎からすぐ申し込めるようにした

  - 校舎紹介は、写真・住所・最寄り駅・地図を同じ並びのカードにそろえ、校舎同士を比べやすくした
  - 見出しや装飾は SVG で書き出し、スマートフォンでもにじまずに表示されるようにした
  - メインタイトルなどは PC 用とスマートフォン用を用意し、画面幅に合わせて切り替えた
- 使用技術: HTML, CSS(Sass) 【 デザインツール: Figma 】

# 個人開発

## わたしたちのSLE

- カテゴリ: SLE(全身性エリテマトーデス)の患者さん・ご家族向け情報サイト(個人運営)
- 期間: 2022年 〜 現在(2026年6月にリニューアル)
- URL: https://our-sle.info/
- 役割: 企画、デザイン、コーディング、WordPress オリジナルテーマの実装、運用
- 工夫した点:
  - 読む人の状況(初めて診断された・疑いと言われた・ご家族)や目的(困っている・調べたい)から情報を探せる導線にした
  - 「#だるさ」「#不安」などの気になる言葉から関連ページへ移動できるタグを用意した
  - 既存テーマを使わず、WordPress のオリジナルテーマを一から実装した
  - アンケート結果を、固定ページテンプレートと CSS の棒グラフで表示し、共通クラスで各回のページに使い回せるようにした
  - 色を CSS カスタムプロパティで管理し、CSS ネストで記述して、Sass を使わずに保守しやすい構成にした
- 使用技術: HTML, CSS(CSS ネスト / カスタムプロパティ), JavaScript, PHP(WordPress オリジナルテーマ) / Docker

## からだの記録アプリ

- カテゴリ: お薬と生理などを記録する Webアプリ(個人開発)
- 期間: 2026年7月公開(制作期間 3日)
- URL: https://bleeding-tracker.vercel.app/
- 役割: 企画、ロゴデザイン、Web デザイン、実装(Claude Code と協働)
- 概要: 既存の生理管理アプリは妊活や若い世代向けが多いため、閉経間近の世代に向けて制作。婦人科で医師に経過を説明しやすくすることを目的にした
- 工夫した点:
  - 生理の周期が一目で分かる表示にし、カレンダーで体調の変化を比べられるようにした
  - アカウント登録をしなくても、端末のブラウザ内に保存して使い始められるようにした
  - あとから登録した場合に、端末内の記録をサーバーへ引き継げるようにした
  - 企画・要件・画面設計を自分で決め、実装は Claude Code と協働して 3日で公開まで進めた
- 使用技術: JavaScript(Next.js / React), Tailwind CSS, Vercel
- 開発方法: Claude Code を使用した AI 協働開発(エディタ: VS Code)

## カミワザ(アシスタントnote)

- カテゴリ: 美容師アシスタントが、先輩から教わった技術を記録する Web アプリ(個人開発)
- 期間: 【2026年 〜 開発中】
- URL: https://kamiwaza-hair.net/
- 役割: 企画、アイコン・画面デザイン、設計、実装(Claude Code と協働)
- 概要: 美容師アシスタント時代に、教わったことを紙のノートに書き残す作業が一番大変だった経験から、当時の自分が欲しかった記録アプリとして制作
- 工夫した点:
  - 「技術 → 工程 → 教わったこと(先輩ごと)/ 自分の気づき」という構成にし、教わった内容と自分の気づきを分けて残せるようにした
  - 先輩によってコツが違うため、同じ工程に先輩ごとのメモを登録できるようにした
  - まずバックシャンプー(全15工程)だけで動くものを作り、他の技術はあとから追加できる設計にした
  - 技術・練習・座学・小テスト・検索・設定のタブ構成にし、記録だけでなく復習にも使えるようにした
  - 美容師としての実体験をもとに、記録する項目と画面構成を自分で決め、実装は AI と協働して進めた
- 使用技術: HTML, CSS, JavaScript, PHP 
- 開発方法: Claude Code を使用した AI 協働開発

## マキコのメモ

- カテゴリ: Notion のようにページ単位でメモを管理する Web アプリ(個人開発)
- 期間: 2026年7月公開(制作期間 2日)
- URL: https://cf817051.cloudfree.jp/
- 役割: 企画、Web デザイン、実装(Claude Code と協働)
- 概要: Notion のようなメモアプリを自分で作ってみたいと考え、フレームワークを使わずに制作
- 工夫した点:
  - Notion から書き出した Zip ファイルを読み込み、これまでのメモをそのまま取り込めるようにした
  - ログインせずに端末内だけに保存する使い方と、ログインして保存する使い方の両方を選べるようにした
  - バックアップの書き出しと読み込みを用意し、データを自分で保管・復元できるようにした
  - パスコードによるロックを付け、メモを他の人に見られにくくした
  - コードを書いたメモは色分け表示されるようにし、技術メモとして読みやすくした
- 使用技術: HTML, CSS, JavaScript, Firebase, JSZip, highlight.js
- 開発方法: Claude Code を使用した AI 協働開発(エディタ: VS Code)
